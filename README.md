# 📚 English Conversation Study with NotebookLM

## 📖 Contexto

Este repositório documenta meu processo de aprendizagem de conversação em inglês utilizando o NotebookLM como ferramenta de apoio aos estudos.

O objetivo é reunir fontes de estudo, testar diferentes estratégias de prompts e registrar os resultados obtidos, criando um material organizado para futuras revisões e prática da conversação.

## 🎯 Objetivos

- Melhorar minha conversação em inglês.
- Ampliar meu vocabulário para situações do dia a dia.
- Aprender expressões utilizadas por falantes nativos.
- Praticar diálogos em diferentes contextos.
- Criar um conjunto de prompts reutilizáveis para revisão dos estudos.
- Documentar todo o processo de aprendizagem utilizando o NotebookLM.
